# 星刃 · STELLAR EDGE

> 霓虹纵向弹幕射击 · 纯 Canvas 2D 手写引擎 · 零运行时依赖

一款打开即玩的纵版打飞机。四种可切换的武器模组、随击杀成长的强化系统、六种敌机、每 5 波一次的多阶段 BOSS，以及全套粒子 / 泛光 / 屏幕震动特效。

**在线试玩：** https://l1scn.github.io/stellar-edge/

---

## 玩法

纵版卷轴射击。机体**自动连射**，你只需要专心走位躲弹。

- 三条命，血量 100，受击后有无敌帧
- 击落敌机积累**能量**，自动提升**强化等级 Mk**，每级全部伤害 **+11%**
- 拾取道具切换武器、获得限时增幅
- 每 5 波出现 BOSS，血量掉到 67% / 34% 时进入狂暴（射速加快、机体泛红、核心变红）

### 操作

| 动作 | 键盘 | 触屏 / 鼠标 |
| --- | --- | --- |
| 移动 | `方向键` / `WASD` | 拖动画面（指针与机体保持相对位置） |
| 炸弹（清屏 + 全体伤害） | `空格` | — |
| 暂停 / 继续 | `P` | 底部「暂停」按钮 |
| 开始 / 重开 | `空格` · `Enter` | 点击画面 |

切到其他标签页会自动暂停。

## 武器模组

火力等级（`P`，1→5）对**所有武器**生效，决定弹数/强度。

| 模组 | 道具 | 行为 | 定位 |
| --- | --- | --- | --- |
| **等离子** | 初始 | 1→8 路直射弹幕 | 均衡 |
| **激光** | `L` | 机体射出**贯穿全屏**的持续光束，一条线上的敌人同时受伤 | 清纵列、稳定输出 |
| **追踪** | `M` | 自动锁敌导弹，初始扇形散开后转向最近目标，火力越高导弹越多（1→5 枚） | 不用瞄准 |
| **霰弹** | `R` | 6→10 发扇形弹丸，射程 630px | 贴脸最高爆发 |

拾取与当前相同的模组会**同调**，转化为 +1 火力，不会浪费。

| 敌机 | 出场 | 行为 |

### BOSS 招式

五套招式循环，每套持续 4.4 秒：环形弹幕 → 瞄准扇形 → 双臂螺旋 → 召唤僚机 + 三向扫射 → **弹幕墙**（11 路齐射，留 3 格移动缺口）。

### 成长曲线

```
敌人血量倍率 hpMul(w) = 1 + (w-1) × 0.17 + max(0, w-10) × 0.14
   第 1 波 ×1.00  →  第 5 波 ×1.68  →  第 10 波 ×2.53  →  第 20 波 ×5.63
我方伤害倍率 = 1 + Mk × 0.11
```

敌人血量与你的强化同步成长，两边都在涨。

## 本地运行

无需构建、无需依赖。因为用了 `file://` 之外的常规脚本与 `localStorage`，建议起个静态服务器：

```bash
# 任选其一
npx serve stellar-edge
python -m http.server 8000 --directory stellar-edge
```

或者直接用浏览器打开 `stellar-edge/index.html`（用 `file://` 打开也能玩，只是部分浏览器会限制 localStorage）。

仓库自带一个无头测试，用假的 DOM / Canvas 驱动真实引擎，覆盖四种武器、六种敌机、BOSS 五套招式、11 种道具、暂停冻结、死亡结算与重开：

## 技术实现

- **零依赖**：没有框架、没有构建步骤，`game.js` 就是浏览器直接执行的原生脚本
- **固定步长**：`requestAnimationFrame` 渲染 + 固定 60Hz 逻辑步长累加器，高分屏不会加速
- **泛光**：主画布降采样到 1/4 尺寸的隐藏画布 → 高斯模糊 → 加性回叠，霓虹感的核心
- **渐变复用**：所有渐变在初始化时预建并配合 `translate` 使用，避免逐帧分配
- **单一伤害入口**：所有伤害都经过 `hitEnemy()`，强化倍率只在一处生效，新增武器不会漏算
- **音效**：WebAudio 实时合成（振荡器 + 噪声缓冲），不支持时静默降级
- **持久化**：最高分存 `localStorage`
